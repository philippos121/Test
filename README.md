# DOS Tennis Game

A simple terminal-based tennis game (Pong) written in Python.

## Requirements

- Python 3.x
- curses library (included in standard Python installation on Linux/Mac)

## How to Run

```bash
python3 tennis_game.py
```

## Controls

- **Player 1 (Left Paddle)**: W (up) / S (down)
- **Player 2 (Right Paddle)**: Arrow UP / Arrow DOWN
- **Quit Game**: Q

## Game Rules

- Two players control paddles on opposite sides of the screen
- Hit the ball back and forth
- If the ball passes your paddle, your opponent scores a point
- First player to... well, there's no win condition, so play as long as you want!

## Features

- Classic Pong-style gameplay
- ASCII graphics for that retro DOS feel
- Two-player local multiplayer
- Real-time score tracking

Enjoy the game!
