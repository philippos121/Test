About

MiniLLM runs AI models directly on your iPhone via iSH.
No cloud, no tracking, 100% private.

Models are stored in ~/.minillm/models/

OpenAI-Compatible API

Use any OpenAI-compatible client with your local model.

POST /v1/chat/completions
curl http://localhost:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "messages": [ {"role": "user", "content": "Hello!"} ], "max_tokens": 256, "stream": false }'
POST /v1/completions
curl http://localhost:8080/v1/completions \ -H "Content-Type: application/json" \ -d '{ "prompt": "Once upon a time", "max_tokens": 128 }'
GET /v1/models
GET /health
GET /v1/status

Full system status including config and model catalog.

Python Client

from openai import OpenAI client = OpenAI( base_url="http://localhost:8080/v1", api_key="not-needed" ) response = client.chat.completions.create( model="local", messages=[ {"role": "user", "content": "Hello!"} ] ) print(response.choices[0].message.content)
